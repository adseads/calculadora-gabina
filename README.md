# Calculadora de preços · Gabina Impressões 3D

Calcula o custo real de cada peça impressa na Bambu Lab A1 Combo (filamento, energia, desgaste, falhas, mão de obra, embalagem, taxas e custos fixos) e sugere preços em 3 cenários: Amigos & família, Lucro OK e Empresas.

Também importa peso, tempo e carretéis direto do arquivo do Bambu Studio (.3mf ou .gcode.3mf).

Versão rápida: https://adseads.github.io/calculadora-gabina/
Versão completa: https://adseads.github.io/calculadora-gabina/completa.html
